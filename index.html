SunSense: rooftop solar sizing and payback calculator

Enter a location, monthly units or bill, and roof area. SunSense returns the system size in kW, yearly generation, cost before and after the PM Surya Ghar subsidy, savings, payback and CO₂ saved, for any home in India.

  • Roof-specific simulation using PVGIS and NASA POWER solar data; results cross-checked against the official PVGIS tool.
  • State electricity tariffs from official board orders, plus a 25-year grid-versus-solar comparison.
  • Serverless backend on AWS Lambda, API Gateway and S3. Led a 4-person team; built the app and AWS backend.
